## Известные ограничения доказательств

- В логах присутствуют ошибки/предупреждения Windows OSHI/WMI/Perflib до загрузки BreweryX. Они есть и в исходном запуске; тесты плагина, SQLite и выключение проходят. Утверждения «в серверном логе вообще нет ошибок» нет.
- Проверен конкретный Paper build 169, а не все существующие и будущие сборки 26.3; сервер сообщает о более новых сборках. Релиз плагина остаётся бетой.
- Не проверены реальным клиентом: взаимодействие с котлами/бочками/варочной стойкой, выпивание и эффекты опьянения, чат, права, PvP и многопользовательская игра.
- Не проверены реальные сторонние интеграции, пользовательские аддоны, MySQL/MongoDB, миграция произвольной старой базы и длительная нагрузка.
- Не заявлена совместимость со Spigot, Folia, Purpur или другими версиями Minecraft. В descriptor API 26.3, Folia support false.
- Исходный сервер/мир пользователя не запускался и не менялся.

## Лицензии и комплект

GPLv3 и уведомление об изменениях включены в итоговый JAR. MIT-тексты для Okaeri Configs, UniversalScheduler и PaperLib и Apache-2.0-тексты/уведомления для Gson, HikariCP и MongoDB Driver включены отдельно. Необязательные API плагинов, Paper API и тестовый плагин не включаются в runtime JAR.

Чистый полный исходный комплект не включает JAR чужих API: `prepare-apis.ps1` получает LogBlock из закреплённого исходного commit и Movecraft из официального релиза, проверяя их SHA-256. Соответствующие исходники самого порта и сборочные файлы предоставляются в `-source.zip`; runtime JAR и архив проверяются в `dist/checksums.sha256`.

Репозиторий, загрузка файла на площадку, одобрение модерацией и публичная доступность не заявлены: внешней публикации ещё нет. Лицензионные и площадочные условия вынесены в `publication/PUBLISHING-STEP-BY-STEP.ru.md`.
