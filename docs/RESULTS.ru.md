# BreweryX beta.5 — обычная трава

Дата: 2026-10-23. Paper 26.3 build 169, Java 25. Локальная бета, не опубликована.

Jägermeister теперь использует SHORT_GRASS/10, дремучая смесь — SHORT_GRASS/5.
Однократная миграция меняет материал TALL_GRASS на SHORT_GRASS только у двух соответствующих ID
в recipes.yml и старом разделе recipes основного config.yml. Перед изменением каждого файла
создаётся копия с суффиксом .before-short-grass-beta5.bak. Сохраняются количество ингредиентов,
другие параметры рецептов, пользовательские названия и отключённое состояние.
После сохранения additional-recipes-version: 2 последующие правки администратора сохраняются.
Удалённые рецепты не восстанавливаются этой поправкой.

## Проверки конечного JAR

- Чистая автономная сборка: успешно; 23 JUnit-теста, 0 провалов/ошибок.
- Новая установка на отдельном настоящем Paper: 157 проверок.
- Обновление с фактическим recipes.yml beta.4: 188 проверок.
- Проверены все 29 записей прежнего файла (28 включённых напитков и отключённый пример):
  кроме двух замен ингредиента их значения совпадают. Копия перед миграцией сохраняет старые значения.
- Проверены точное количество ингредиентов и приготовление всех пяти добавленных напитков через
  BIngredients.cook, Brew.distillSlot, Brew.age, качество 10, крепость, эффекты и сериализация предметов.
- Названия EN/RU и поиск по русским названиям прошли проверки.
- Отдельно проверены отключённый изменённый рецепт, нестандартное количество травы, устаревший
  раздел config.yml, посторонний рецепт с высокой травой и повторная загрузка конфигурации.
- Оба завершённых серверных запуска: READY=True, EXIT=0, штатное отключение плагина.
- SHA-256 тестовых JAR, сборки и копии для выдачи сверяются. Значения сохранены в
  delivery-verification.json, warehouse-copy.json и checksums.sha256.

## Границы

Серверы запускались скрыто на 127.0.0.1:25643 в отдельных тестовых мирах. Проверки автоматические;
подключённого клиента, ручного приготовления и визуального действия эффектов не было.
Полный набор проверок русификации beta.4 здесь повторно не запускался: изменены ингредиенты и их миграция.
В журналах присутствуют прежние сообщения Windows OSHI/WMI/Perflib до включения BreweryX.
Уже готовые бутылки и их ингредиенты массово не переписываются.
