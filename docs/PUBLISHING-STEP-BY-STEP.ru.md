# Обновление существующего GitHub-репозитория до beta.5

Репозиторий: https://github.com/vladnow/BreweryX-Paper-26.3
Ветка порта: `paper-26.3-port`. Тег: `v3.7.1-paper26.3.1-beta.5`.

## Исходники

1. Откройте Code и выберите `paper-26.3-port`.
2. В корне репозитория нажмите Add file → Upload files.
3. Загрузите обновлённые файлы с сохранением путей. При использовании подготовленного браузерного
   комплекта загружайте содержимое порций из `01-upload` по очереди, каждый раз из корня репозитория.
   Не загружайте сами папки с названиями порций и не кладите исходники ZIP-архивом в Code.
4. После каждой порции выберите Commit directly to the paper-26.3-port branch и Commit changes.
5. Сверьте пути: build.gradle.kts лежит в корне, Java-файлы внутри src/main/java, ресурсы внутри src/main/resources.
6. Скачайте Code → Download ZIP и сравните его с манифестом комплекта. Локальный CHECK-UPLOAD.cmd
   проверяет все требуемые файлы по SHA-256, не обращается к сети и не изменяет репозиторий.

Если ветка защищена, используйте отдельную ветку, загрузите туда все порции, проверьте архив
и создайте Pull Request внутри этого же репозитория в `paper-26.3-port`. Не направляйте его в BreweryTeam/BreweryX.

## Релиз

1. Откройте Releases → Draft a new release.
2. В Choose a tag создайте **новый** тег `v3.7.1-paper26.3.1-beta.5`; Target — `paper-26.3-port`.
3. Вставьте подготовленные заголовок и описание beta.5. Отметьте This is a pre-release.
4. Прикрепите четыре файла beta.5: runtime JAR, `-sources.jar`, полный `-source.zip`, `checksums.sha256`.
5. Сохраните черновик через Save draft. Проверьте тег, целевую ветку, имена и размеры четырёх вложений.
6. Нажмите Publish release после проверки. Прежний релиз beta.1 сохраняется.

В `plugins` ставится только runtime JAR. Полный архив исходников нужен для распространения и сборки.
Сохраните LICENSE.txt, PORT-NOTICE.md и уведомления сторонних библиотек. Статус беты и ограничения
тестирования указываются в описании; не заявляйте клиентскую проверку, которая не проводилась.

## Actions

Сценарий Build Paper 26.3 (Java 25) запускается вручную кнопкой Run workflow на вкладке Actions
после загрузки всех исходников. Он подготавливает compile-only API, собирает проект и сохраняет артефакты.
Публикация на другие площадки и отправка сообщений этим комплектом не выполняются.
Подготовленный сценарий ещё не подтверждён запуском в GitHub Actions; локальная сборка подтверждена отдельно.
